🐱 Cat Run
Um jogo de corrida infinita (endless runner) 2D em pixel art, inspirado no clássico jogo do T-Rex do Google Chrome. Assuma o controle de um gatinho destemido, desviando de obstáculos urbanos e acumulando a maior pontuação possível!
